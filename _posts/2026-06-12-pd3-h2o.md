# Pd3 Cluster in OPC Water

This post documents the complete setup, minimization, and equilibration
workflow for a single Pd3 palladium cluster solvated in OPC water, stored in:

```bash
/Users/alokranjan/Downloads/simulations/pd3_water
```

The simulation replicates the methodology from the thesis: *"Interaction of
Palladium Clusters in Different Solvents"*, using the INTERFACE force field
for the metal cluster and the OPC 4-site rigid water model.

## Force Field Parameters

### Pd3 Cluster — INTERFACE Force Field

The Pd3 cluster is modelled as a rigid asymmetric triangle with three
chemically distinct vertex labels (Pd1, Pd2, Pd3) to preserve the
molecule topology through the `fftool` parser. All three atoms carry
identical physical parameters from Heinz et al. (2008).

| Parameter | Value | Source |
|---|---|---|
| Mass | 106.42 AMU | Standard Pd |
| Charge | 0.0 e | Zero-valent metallic state |
| LJ ε | 3.58509 kcal/mol | 15.0 kJ/mol ÷ 4.184 |
| LJ σ | 2.48000 Å | Heinz 2008, Table 2 |
| Pd1–Pd2 bond | 2.9440 Å | DFT-optimised geometry |
| Pd1–Pd3 bond | 2.7476 Å | DFT-optimised geometry |
| Pd2–Pd3 bond | 2.7476 Å | DFT-optimised geometry |
| Triangle angles | 57.61°, 57.61°, 64.79° | Sum = 180.01° ✓ |

All Pd bonds are declared `constrained` (`k = 0`). The cluster is held
rigid during dynamics by `fix rigid/small molecule`, which performs its
own time integration and must not be placed inside a general NPT
integrator group.

### OPC Water — Optimal Point Charge Model

OPC is a 4-site rigid model (Izadi et al., 2014). In LAMMPS the virtual
M-site is not an explicit atom; it is displaced on-the-fly by
`pair_style lj/cut/tip4p/long` at offset `d_OM = 0.1594 Å` from Ow.

| Parameter | Value | Source |
|---|---|---|
| Ow mass | 15.999 AMU | |
| Hw mass | 1.008 AMU | |
| Ow charge | −1.3582 e | −2 × q(Hw), sits at Ow position |
| Hw charge | +0.6791 e | Izadi 2014 |
| Ow LJ ε | 0.21280 kcal/mol | 0.890359 kJ/mol ÷ 4.184 |
| Ow LJ σ | 3.16655 Å | Izadi 2014 |
| Hw LJ ε / σ | 0.0 / 0.0 | No LJ on H (TIP4P convention) |
| O–H bond | 0.8724 Å | OPC geometry |
| H–O–H angle | 103.60° | OPC geometry |
| M-site offset | 0.1594 Å | Along bisector from Ow |

### Cross-pair Coefficients — Pd ↔ Water

Pd–Ow cross terms follow the Lorentz–Berthelot convention: arithmetic
mean for σ, geometric mean for ε.

$$\sigma_{\text{Pd-Ow}} = \frac{2.48000 + 3.16655}{2} = 2.82328\ \text{Å}$$

$$\varepsilon_{\text{Pd-Ow}} = \sqrt{3.58509 \times 0.21280} = 0.87352\ \text{kcal/mol}$$

All Pd–Hw cross terms are explicitly zero (Hw carries no LJ site).
The Ow–Hw cross term is also set explicitly to zero to suppress the
non-zero value that arithmetic mixing would otherwise auto-generate
(`ε_mix = 0.10640 kcal/mol`).

## Workflow

### Step 1 — Force Field Files

Two `.ff` files were prepared for `fftool`:

- `pd3.ff` — Pd1/Pd2/Pd3 LJ parameters, rigid bond and angle geometry
- `opc.ff` — Ow/Hw LJ parameters, OPC bond/angle geometry, M-site charge

### Step 2 — Packing with Packmol

```bash
fftool 1 pd3.xyz 7205 water.xyz -b 60
packmol < pack.inp
fftool 1 pd3.xyz 7205 water.xyz -b 60 -l
```

`fftool` generates the Packmol input, Packmol places molecules
without overlaps, and `fftool -l` converts the packed coordinates
into `data.lmp` and `field.lmp`.

> **Charge correction required:** `fftool` writes Ow with `q = 0.0`.
> The script applies `set type 4 charge -1.3582` after `read_data`
> to place the OPC negative charge on Ow, as required by
> `pair_style lj/cut/tip4p/long`.

### Step 3 — Energy Minimisation (`in.minimization`)

Packmol produces valid but not energy-minimised initial coordinates.
Bad contacts (atom separations < σ) produce forces of thousands of
kcal/mol/Å that cause integrator divergence at MD Step 1 without
a minimisation pass.

#### Key design decisions

**Why not SHAKE during minimisation?**
LAMMPS cannot run iterative SHAKE without a timestep. It substitutes
each O–H constraint with a harmonic spring of
`k_bond = 1,987,206 kcal/mol/Å²`. With 14,410 O–H bonds, the spring
residual forces sum to a Fnorm floor of ~2,100 kcal/mol/Å that
steepest-descent cannot descend through.

**Why not remove all bond springs (k = 0)?**
Hw carries zero LJ. With `k = 0` and special_bonds zeroing the
1-2 intra-molecular Coulomb, Hw feels only the Coulomb attraction
from neighbouring Ow atoms with no repulsive barrier. The result
is a topology collapse: Hw atoms migrate into neighbouring Ow
Coulomb wells, and PotEng dropped 715,000 kcal/mol in 100 steps
before PPPM failed.

**Solution — temporary harmonic springs**
Bond type 4 (O–H) is given `k = 1,000 kcal/mol/Å²` during
minimisation only. This is 2,000× softer than the SHAKE substitution
spring, but strong enough to prevent Hw migration
(`F_spring at 0.1 Å = 100 kcal/mol/Å` > Coulomb attraction at 2 Å).
As the O–H bonds relax to `r_e = 0.8724 Å`, the spring force
approaches zero and Fnorm converges to the real LJ + Coulomb baseline.
Both springs are reset to `k = 0` before `write_data`.

#### Minimiser settings

```
pair_style  lj/cut/tip4p/long 4 5 4 4 0.1594 12.0
kspace_style pppm/tip4p 1.0e-5
comm_modify  cutoff 15.1
min_style    sd
```

**Stage 1** — `dmax = 0.01 Å`, `ftol = 50`, `maxiter = 1000`
Triage pass. Caps per-step displacement to prevent box overshoot
when Fnorm > 3,000. Clears all repulsive contacts; pressure dropped
from 40,509 → 41.8 atm in 1,000 steps.

**Stage 2** — `dmax = 0.10 Å`, `ftol = 1.0`, `maxiter = 20,000`
Primary bulk water relaxation. Steepest-descent on the smooth
LJ + Coulomb surface after bad contacts are cleared.

**Stage 3** — `dmax = 0.10 Å`, `ftol = 1×10⁻⁴`, `maxiter = 50,000`
Final convergence pass. Total: 71,000 minimisation cycles.

#### Convergence achieved

| Metric | Initial (Step 0) | Final (Step ~71,000) |
|---|---|---|
| PotEng | −59,933 kcal/mol | −106,300 kcal/mol |
| Fnorm | 3,859 kcal/mol/Å | ~4 kcal/mol/Å |
| Max force component | 73.3 kcal/mol/Å | ~1.5 kcal/mol/Å |
| Pressure | 40,509 atm | ~−1,876 atm |

> The residual pressure of −1,876 atm is corrected by the NPT
> barostat within the first ~10 ps of equilibration.

#### Mandatory LAMMPS parser order

```
bond_style / angle_style   ← before read_data (Bond/Angle Coeffs)
pair_style                 ← before read_data (Pair Coeffs section)
kspace_style               ← before read_data (safe)
read_data                  ← defines box and atom types
pair_coeff                 ← after read_data (needs atom types)
set type 4 charge -1.3582  ← after read_data
```

This ordering was established through systematic error resolution
across multiple runs. Violations produce hard parser errors:
`"Must define bond_style before Bond Coeffs"`,
`"Must define pair_style before Pair Coeffs"`, and
`"Pair_coeff command before simulation box is defined"`.

### Step 4 — NPT Equilibration (next stage)

The minimised system (`minimized.data`, `minimized.restart`) feeds
into the NPT equilibration script. Key changes from minimisation:

```lammps
unfix  FREEZE_PD
fix    SHAKE_WAT  WATER  shake 1.0e-4 20 0 m 15.999 1.008
fix    NPT        all    npt temp 298.15 298.15 100.0 iso 1.0 1.0 1000.0
```

SHAKE now operates as true geometric constraints (not spring
substitutions) because a timestep exists. Water geometry is restored
to exact OPC geometry (`r_OH = 0.8724 Å`, `∠HOH = 103.60°`) on the
first dynamics step.
